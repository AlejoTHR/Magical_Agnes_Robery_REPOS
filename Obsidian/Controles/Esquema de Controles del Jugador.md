Este apartado recoge la distribución de controles utilizada durante la partida. La configuración ha sido diseñada para ofrecer acceso rápido a las acciones principales de exploración, interacción y uso de habilidades mágicas mediante mando.

## Distribución de Entradas

| Control                        | Función                  |
| ------------------------------ | ------------------------ |
| Stick izquierdo                | Movimiento del personaje |
| Botón B                        | Saltar                   |
| Botón A                        | Interactuar              |
| Botón X                        | Esconderse               |
| Botón Y                        | Esconderse               |
| Gatillo superior izquierdo (L) | Magia de Viento          |
| Gatillo superior derecho (R)   | Magia de Fuego           |
| Gatillo trasero derecho (ZR)   | Magia de Agua            |

## Movimiento

El desplazamiento de Agnes se realiza mediante el stick analógico izquierdo, permitiendo el movimiento horizontal y el control direccional necesario para la exploración de los distintos escenarios.

## Salto

La acción de salto está asignada al botón **B**, permitiendo superar obstáculos, acceder a plataformas elevadas y desplazarse por las diferentes zonas del nivel.

## Interacción con el Entorno

El botón **A** se utiliza para interactuar con los elementos del escenario que admiten acciones contextuales, como palancas, mecanismos de puzles o puertas desbloqueadas.

## Sistema de Ocultación

Los botones **X** e **Y** permiten activar la mecánica de ocultación cuando el jugador se encuentra en una zona válida para ello.

## Magias Elementales

Las habilidades mágicas disponibles durante la aventura se encuentran asociadas a los gatillos superiores y traseros del mando:

- **Magia de Viento (L):** habilidad orientada a la movilidad aérea.
    
- **Magia de Fuego (R):** habilidad asociada a acciones ofensivas y de impulso.
    
- **Magia de Agua (ZR):** habilidad centrada en movimientos rápidos y desplazamientos especiales.
    

## Consideraciones de Diseño

La distribución de controles busca mantener separadas las acciones de movimiento, interacción y uso de habilidades, facilitando que el jugador pueda acceder a todas las mecánicas principales de forma intuitiva sin recurrir a combinaciones complejas de botones.
